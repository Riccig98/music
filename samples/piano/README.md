# Piano samples

These acoustic piano samples are derived from the FreePats "Old Piano FB" sound bank, recorded by Piotr Barcz and published under the Creative Commons CC0 1.0 public domain dedication.

Source project:
- https://freepats.zenvoid.org/Piano/honky-tonk-piano.html
- https://github.com/smpldsnds/freepats-old-piano-fb

This app uses a reduced set of OGG samples as pitch anchors to keep the PWA small and fully offline.
