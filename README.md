# Chord Ear Trainer

PWA per allenamento uditivo su note e accordi, ottimizzata per smartphone in orizzontale.

## Funzioni
- Accordi: Facile, Jazz, Avanzato
- Note: 1 nota o 2 note simultanee
- Timbri: Piano, E-Piano, Organo
- Storico automatico con precisione, errori, tempo e grafici
- Filtri per periodo, modalità e livello
- Funzionamento offline dopo il primo caricamento
- Installabile sulla home come PWA

I dati dello storico restano nel browser del dispositivo tramite `localStorage`.
